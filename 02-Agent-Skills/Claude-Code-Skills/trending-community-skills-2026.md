## 7. alchaincyf/darwin-skill

- **Stars**: 2,167
- **Language**: HTML
- **License**: N/A
- **Created**: 2026-04-13
- **Supports**: Claude Code, Codex, OpenClaw, Trae, CodeBuddy, any SKILL.md-compatible agent

**Description**: 达尔文.skill —— 一个让你的Skill无限进化的系统：评估→改进→测试→保留或回滚 | Autoresearch-inspired autonomous skill optimization for Claude Code. Evaluate, improve, test, keep or revert.

### Key Features
- Autonomous optimization loop (Evaluate → Improve → Test → Keep or Revert) inspired by Karpathy's autoresearch pattern
- 8-dimension scoring rubric (100 points total): 60 from static structural analysis, 40 from live test-prompt execution
- Ratchet mechanism: scores only go up — improvements are kept, regressions are automatically reverted via git
- Independent scoring via sub-agents: prevents self-evaluation bias (the agent that edits the skill is not the one that scores it)
- Human-in-the-loop at every phase boundary: system runs autonomously within phases but pauses for user confirmation between them

**Problem Solved**: When you have 60+ agent skills, manual maintenance becomes impossible. Traditional skill review is purely structural (checking format, numbering, paths). Darwin-skill evaluates both structural quality AND real-world effectiveness against test prompts, then only keeps changes that produce measurable improvement — an evolutionary ratchet for skill optimization.
